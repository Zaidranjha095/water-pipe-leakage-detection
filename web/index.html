Smartphone audio water-pipe leakage detection

A compact CNN listens to a one-second clip and classifies it as leak, no leak, or environmental noise. The weights are public, and this page runs the same network in the browser from a WAV file.

Problem

A pipe leak can run for a long time before anyone sees water. A short microphone recording is cheap to capture at a tap or joint, and it is enough signal for a first automated guess.

This project trains a small convolutional network for that three-way decision, saves the weights in a form an evaluator can download, and demonstrates predictions without a GPU server.

Method

  • Dataset: Zenodo 18631450 water-distribution acoustic clips.
  • Features: 16 kHz, 1.0 s, 64-bin log-mel spectrogram, shape 1×64×59.
  • Architecture: four-block CNN in model.py, 98,019 parameters.
  • Checkpoint: weights/model.pth with key state_dict.
  • Reference inference: python predict.py --audio <path>.

Dataset and code

Most leak and no-leak recordings come from an outdoor leakage-detection training base in Dongguan. Environmental-noise clips mix on-site noise with public background audio. The split is stratified, 70% train / 15% validation / 15% test, seed 42. The archive is downloaded by download_dataset.py and is not stored in Git. One test clip per class is kept in samples/.
